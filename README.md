# Task Manager – Gestionnaire de tâches

Task Manager est une application en ligne de commande écrite en Python. Elle permet d'ajouter, consulter, terminer et supprimer des tâches. Les données sont enregistrées localement dans `tasks.json`.

## Fonctionnalités
- Ajouter une tâche.
- Afficher toutes les tâches.
- Marquer une tâche comme terminée.
- Supprimer une tâche.
- Sauvegarder automatiquement les données au format JSON.

## Prérequis
- Python 3.9 ou version ultérieure.
- Git (pour les exercices de versionnement).

## Lancement
Depuis le dossier du projet :

```bash
python src/main.py
```

Sous Windows, si `python` n'est pas reconnu :

```powershell
py src/main.py
```
